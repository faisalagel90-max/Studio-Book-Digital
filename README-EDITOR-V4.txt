DIGITAL BOOK STUDIO — EDITOR V4

Perbaikan editor:
- Teks selalu memiliki fallback "Teks baru" agar objek kosong tidak menghilang.
- Rendering teks dibuat lebih stabil dan terlihat di atas elemen lain.
- Teks memiliki line-height, wrapping, overflow, dan z-index yang aman untuk layar HP.
- Ukuran teks divalidasi agar tetap 8–180 px.
- Tombol Teks membuat objek teks yang langsung bisa dipilih/diedit.
- Foto, shape, stiker, posisi, ukuran, rotasi, layer, duplikat, hapus, dan undo/redo tetap dipertahankan.

Cara memakai:
1. Ekstrak ZIP.
2. Upload seluruh isi folder ke repository GitHub, bukan file ZIP-nya.
3. Pastikan index.html berada di root repository.
