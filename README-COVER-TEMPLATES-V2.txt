DIGITAL BOOK STUDIO — HOME CREATE V2 + COVER TEMPLATES V2

Perubahan utama:
- Template cover menjadi layout berbasis objek yang dapat diedit, bukan gambar datar.
- Template Classic, Scrapbook, Love Story, Birthday, Travel Journal, Photo Album, Vintage Journal, dan Minimalist.
- Preview template memakai render desain cover.
- Thumbnail Perpustakaan memakai cover hasil render, bukan kertas kosong + judul.
- Buku lama yang belum memiliki template akan diberi cover template berdasarkan tema saat ditampilkan.
- Template hanya menjadi titik awal; buku baru masuk Perpustakaan setelah dibuat/disimpan.
- Aset HOME-CREATE V2 dipertahankan.

Cara pakai:
1. Ekstrak ZIP.
2. Buka index.html melalui web/PWA yang biasa digunakan.
3. Pilih Template atau Buat Buku.
4. Masuk editor dan ubah elemen cover.
5. Simpan buku; cover akan tampil di Perpustakaan.
